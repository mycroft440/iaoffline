# Pacotes de linguagem do Canvas de código

Estes arquivos JSON são opcionais e não contêm executáveis, compiladores, parsers ou bibliotecas nativas.

O aplicativo base mantém apenas o editor. Quando o usuário escolhe **Configurações → Linguagens do editor → Baixar**, o app baixa o JSON correspondente diretamente deste diretório e usa o campo `prompt` como contexto especializado para a IA durante uma edição por linha.

Formato atual: `schemaVersion = 1`.
